baboon-acoustics — interactive demos

Self-contained HTML demos of the analyses of the article: each page embeds the audio (base64) and the precomputed analysis data, so it runs offline in any browser. Plots are interactive: toggles, hover readouts, playback cursor, click-to-seek, mouse-wheel zoom. Regenerate with python scripts/make_demos.py.

Formant tracks

Praat/Burg N=4 vs N=6 vs merged trajectories against the reference, with VTL estimates and synchronized audio playback.

Spectrogram + formants

Short-term spectrogram with Praat, IAIF and F0 overlays; playback cursor and seek.

F0 contours

Filtered vs raw autocorrelation F0 for the four wahoos; the disagreements flag subharmonic dynamics.

Glottal source

IAIF pulse train (wheel zoom), single glottal cycle and Hilbert phase portrait.

Part of the baboon-acoustics repository (supplementary code of the article, anonymized for review). See the repository README for the Python API.
