\bigskip
\noindent This document describes the methods and the software used to
produce every figure of the article and of the present supplement. The
analyses are implemented in the documented Python package \pkg{}:
reading a WAV file, performing formant estimation via Parselmouth,
applying Iterative Adaptive Inverse Filtering (IAIF) to extract the
glottal source and vocal-tract filter, and producing the figures in this
supplement are one-liners with the package, as detailed in
Section~\ref{sec:methods}. The package is archived at the root of the
repository together with its user documentation, guided example, unit
tests and interactive demos. The \emph{original} scripts used during the
study are archived verbatim in
\file{supplementary/original\_scripts/}; Section~\ref{sec:provenance}
gives the function-by-function mapping between those frozen scripts and
the package, so that every statement of the article can be traced to the
exact code that produced it.

\section{Repository overview}

The repository is organised as follows:
\begin{itemize}
\item \file{baboon\_acoustics/} --- the analysis package. One module per
      concept: \file{audio\_io} (loading, mono conversion, normalisation,
      resampling), \file{formants\_praat} (Praat/Burg formant tracking),
      \file{formants\_iaif} (LPC and Iterative Adaptive Inverse
      Filtering), \file{f0} (fundamental-frequency estimation),
      \file{vtl} (vocal-tract length), \file{glottal} (glottal source
      extraction), \file{plotting} (journal-style figures). Every
      function carries a complete NumPy-style docstring; the compiled
      user guide is \file{docs/baboon-acoustics-documentation.pdf}.
\item \file{scripts/} --- thin command-line programs reproducing each
      figure of the article and of this supplement
      (Section~\ref{sec:figures}).
\item \file{demos/} --- self-contained interactive HTML pages (audio
      embedded in base64, dynamic plots, playback cursor), readable
      offline in any browser or online via GitHub Pages.
\item \file{data/} --- the audio material: the four wahoo calls of the
      sequence (\file{wahoo\_1.wav} \ldots{} \file{wahoo\_4.wav}), the
      full original recording (\file{The\_Baboon\_Bark.wav}), and the
      reference F0 table (\file{wahoo\_4\_f0\_filtered\_ac.csv}).
\item \file{supplementary/} --- the present document, all figures, and
      the original scripts archived verbatim
      (\file{original\_scripts/}, Section~\ref{sec:provenance}).
\item \file{tests/} --- unit tests sanity-checking every analysis step
      (\file{python -m unittest discover -s tests}).
\end{itemize}

The package requires Python 3.9+ with \file{numpy}, \file{scipy},
\file{matplotlib} and \file{praat-parselmouth}
(\file{pip install -r requirements.txt}); Praat itself need not be
installed.

\section{Methods}
\label{sec:methods}

\subsection{Audio loading and resampling}

\begin{lstlisting}
from baboon_acoustics import load_audio
samples, fs = load_audio("wahoo_4.wav")
\end{lstlisting}
\file{load\_audio(path, target\_fs=44100, normalize=True)} reads a WAV
file, converts stereo to mono by taking the first channel, converts
samples to floating point, normalises the signal to the range $[-1, 1]$
(optional), and resamples to the target sampling frequency
$F_s = 44100$\,Hz with a polyphase filter if necessary. All default
analysis parameters below are expressed at this rate.

\subsection{Formant tracking with Praat's Burg method}

\begin{lstlisting}
from baboon_acoustics import extract_praat_formants
times, formants = extract_praat_formants("wahoo_4.wav", n_formants=4)
\end{lstlisting}
\file{extract\_praat\_formants(audio\_path, n\_formants, formant\_ceiling=5500,
window=0.040, time\_step=0.040, pre\_emphasis=50)} runs Praat's
\emph{To Formant (burg)} command through the Parselmouth interface with
the settings of the article (time step $= 40$\,ms, window length $=
40$\,ms, maximum formant $= 5500$\,Hz, pre-emphasis $= 50$\,Hz). It
returns the frame times and a matrix of shape
$(n_{\mathrm{formants}}, n_{\mathrm{frames}})$ in Hz, with NaN where
Praat found no value. Two helpers support the comparison with
fixed-grid analyses: \file{interpolate\_formants()} resamples tracks
onto an arbitrary time grid (NaN-aware), and \file{fill\_leading\_nan()}
replaces the missing first frame (half-filled window) by the first valid
value.

\subsection{LPC and the Levinson--Durbin recursion}

\begin{lstlisting}
from baboon_acoustics import lpc_levinson, lpc_spectrum_db
a, sigma2 = lpc_levinson(frame, order=60)
freqs, env_db = lpc_spectrum_db(a, sigma2, n_fft=4096, fs=44100)
\end{lstlisting}
\file{lpc\_levinson(x, order)} computes the linear prediction
coefficients of a frame using the Levinson--Durbin recursion. The input
is first mean-centred; the autocorrelation is estimated via FFT for
efficiency. It returns the coefficient vector \file{a} (with
\file{a[0] = 1}) and the residual variance $\sigma^2$; a small
regularisation avoids numerical instability.
\file{lpc\_spectrum\_db()} evaluates the frequency response of the
all-pole filter $H(f) = \sqrt{\sigma^2}\,/\,A(f)$ with
\file{scipy.signal.freqz} and returns the frequency axis (Hz) and the
magnitude spectrum in dB.

\subsection{Iterative Adaptive Inverse Filtering (IAIF)}

\begin{lstlisting}
from baboon_acoustics import iaif_frame
Hvt2, sigma2, gn = iaif_frame(frame, fs, vt_order=60)
\end{lstlisting}
\file{iaif\_frame(frame, fs, vt\_order)} performs one frame of the
two-iteration IAIF algorithm (Alku, 1991) to separate the glottal source
from the vocal-tract filter:
\begin{enumerate}
\item Estimate a first glottal filter $H_{g1}$ of order 1 via LPC, and
      inverse-filter the frame to obtain $s_1$.
\item Estimate the vocal-tract filter $H_{vt1}$ of order
      \file{vt\_order} on $s_1$.
\item Compute a first source estimate
      $g_1 = \int (H_{vt1} * \text{frame})$ and remove its mean.
\item Estimate a second glottal filter $H_{g2}$ of order 2 on $g_1$,
      inverse-filter the original frame to get $s_2$.
\item Estimate the final vocal-tract filter $H_{vt2}$ (order
      \file{vt\_order}) on $s_2$.
\item Compute the final source signal
      $g_n = \int (H_{vt2} * \text{frame})$ and remove its mean.
\end{enumerate}
The function returns $H_{vt2}$ (LPC coefficients), $\sigma^2$ (residual
variance), and the glottal source signal $g_n$.

\subsection{Formant extraction from the IAIF envelope}

\begin{lstlisting}
from baboon_acoustics import get_frame_formants, iaif_sliding_analysis
\end{lstlisting}
\file{get\_frame\_formants(frame, fs, vt\_order=60, n\_formants=4,
fmax=3500, min\_prominence=2.5, min\_dist\_hz=150)} extracts formant
frequencies from a frame by running IAIF, evaluating the vocal-tract
envelope, and detecting its spectral peaks below \file{fmax} with
\file{scipy.signal.find\_peaks} (minimum prominence 2.5\,dB, minimum
spacing 150\,Hz). The $n_{\mathrm{formants}} + 2$ most prominent peaks
are kept as candidates and the lowest ones in frequency are returned, so
that a strong high-frequency peak cannot mask a genuine low formant;
missing entries are padded with NaN. This single function replaces the
\file{get\_frame\_formants} / \file{get\_frame\_formants\_3} pair of the
archived scripts through its \file{n\_formants} parameter.

\file{iaif\_sliding\_analysis(x, fs, n\_formants=4, \ldots)} applies the
analysis to the whole signal with a sliding Hann window (4096 samples,
75\,\% overlap). For each frame it computes the spectrogram of the
signal, the spectrogram of the glottal source, the envelope
$|H_{vt2}(f)|$ interpolated on a common frequency grid, the F0 track
(below), and the IAIF formant tracks. The result is a named tuple
(\file{times}, \file{freqs}, \file{spectrogram\_db}, \file{glottal\_db},
\file{envelope\_db}, \file{f0\_track}, \file{formants}); it likewise
subsumes the \file{\_3} variant of the archived scripts.

\subsection{Fundamental frequency estimation}

\begin{lstlisting}
from baboon_acoustics import estimate_f0_from_gn, estimate_f0_praat
\end{lstlisting}
\file{estimate\_f0\_from\_gn(gn, fs, f0\_min=50, f0\_max=500,
ac\_threshold=0.3)} estimates F0 from a glottal source segment by
autocorrelation: the mean-centred signal is correlated with itself, the
normalised autocorrelation is searched between the lags corresponding to
\file{f0\_max} and \file{f0\_min}, and the reciprocal of the best lag is
returned; frames whose peak falls below \file{ac\_threshold} (0.3) or
touches the search boundaries return NaN.

\file{estimate\_f0\_praat(audio\_path, use\_prefilter=True, \ldots)}
runs Praat's autocorrelation pitch analysis (\file{to\_pitch\_ac};
floor 30\,Hz, ceiling 800\,Hz, time step 0.01\,s) and returns the
time/F0/strength of the voiced frames. With \file{use\_prefilter=True}
the signal first passes through
\file{gaussian\_lowpass\_filter(samples, fs, cutoff=800,
attenuation=0.03)}, a frequency-domain Gaussian window
$H(f) = \exp\!\left(-(f/\sigma)^2/2\right)$ with
$\sigma = f_{\mathrm{cutoff}} / \sqrt{-2\ln(\alpha)}$ and $\alpha = 0.03$
($-30.5$\,dB at cutoff). This preprocessing replicates the
\emph{filtered autocorrelation} method of Praat 6.4.65 (not available in
the legacy Praat embedded in Parselmouth 0.4.5): attenuating the
spectrum above the F0 range suppresses the subharmonic candidates
responsible for octave-halving errors on calls with nonlinear dynamics
(Fig.~\ref{fig:f0} vs.\ Fig.~\ref{fig:praat}).

\subsection{Vocal tract length estimation}

\begin{lstlisting}
from baboon_acoustics import reby_mccomb_vtl
vtl_cm = reby_mccomb_vtl(formants)
\end{lstlisting}
\file{reby\_mccomb\_vtl(formants, c=350.0)} computes a global
vocal-tract length estimate (cm) with the Reby--McComb method: every
valid (non-NaN) formant measurement contributes one point
(order, frequency) with orders $1, 3, 5, 7, \ldots$ for F1, F2, F3,
F4, \ldots; a least-squares line through the origin,
$F = b \cdot \mathrm{order}$, is fitted across all points of all frames
($b = \sum f_i \cdot \mathrm{order} \,/\, \sum \mathrm{order}^2$), and
$\mathrm{VTL} = c/(4b)$ with the speed of sound $c = 350$\,m/s. The
function accepts any number of formants (the archived scripts'
\file{\_3} and four-formant variants are subsumed) and returns NaN when
fewer than two valid values are available.

\subsection{Glottal source analysis}

\begin{lstlisting}
from baboon_acoustics import (extract_glottal_pulse,
                              extract_glottal_train)
t_pulse, pulse = extract_glottal_pulse(x, fs, 0.26, 0.34)
t_train, train = extract_glottal_train(x, fs)
\end{lstlisting}
\file{extract\_glottal\_pulse(x, fs, t\_start, t\_end)} isolates a
single glottal cycle from a stable segment: the segment (Hamming
windowed) is decomposed by IAIF, the fundamental period is measured from
the autocorrelation of the source, and one period is cut around the
largest absolute excursion (Fig.~\ref{fig:pulse}).

\file{extract\_glottal\_train(x, fs)} reconstructs the full pulse train
by overlap-add of Hann-windowed IAIF estimates (window 4096 samples, hop
1024), trimmed at the edges where too few windows overlap.

\file{normalize\_amplitude(signal, fs, cutoff=50)} removes slow drifts
(floating DC) by subtracting a low-pass filtered version of the signal
and divides by a low-pass filtered envelope; it is applied before the
phase portraits of Figs.~\ref{fig:wa} and \ref{fig:hoo}, where amplitude
modulation would otherwise blur the trajectories.
\file{plot\_phase\_portrait(ax, signal, fs)} draws the Hilbert-plane
portrait of the analytic signal.

\section{Reproducing the figures}
\label{sec:figures}

Each figure is reproduced by one thin command-line script of the
\file{scripts/} folder, which only orchestrates calls to the package:

\begin{lstlisting}[language=bash]
python scripts/make_figure1.py               # article Fig. 1
python scripts/make_figure_multipanel.py     # Fig. 1 + Fig. 2 of this supplement
python scripts/make_figure_ac.py             # Fig. 3 (+ CSV table)
python scripts/make_figure_glottal.py        # Figs. 5 and 6 (--segment wa|hoo)
python scripts/make_figure_f0.py             # F0 contour used in the article
\end{lstlisting}

All scripts default to \file{data/wahoo\_4.wav} --- the last call of the
sequence originally recorded in \file{The\_Baboon\_Bark.wav} and
analysed by Bo\"e et al.\ (2026); the three other calls of the sequence
can be processed by passing their filenames as an argument. The article's
Figure~1 compares the Praat/Burg tracks obtained with $N=4$ and $N=6$
poles, the merged trajectory using the optimal $N$ per segment
(first frame from $N=6$, frames 2--9 from $N=4$, remaining frames from
$N=6$) against the reference data digitized from Bo\"e et al.\ (2026,
their Fig.~10h), with one Reby--McComb VTL estimate per panel.
